M1 Arc is a standalone, offline in-game control panel for Cyberpunk 2077 mods, powered by RED4ext and Dear ImGui.

## Get started

- [Install M1 Arc](/quickstart)
- [Create a mod manifest](/mod-manifest)
- [Native REDscript API](/native-api)
- [Logs and diagnostics](/diagnostics)

<Callout kind="info" title="Stable version">Download the current published build from [GitHub Releases](https://github.com/m1nsook/m1arc/releases) or [Nexus Mods](https://www.nexusmods.com/cyberpunk2077/mods/39311). The [1.1.0 development preview](/development) is not a published release.</Callout>

## Interactive control panel preview

This is a **browser-only demonstration** of the planned 1.1.0 tabs and conditional controls. It does not connect to Cyberpunk, read installed mods or change game settings.

## Offline by design

No accounts, API keys or telemetry are required by the in-game framework. Community documentation; not affiliated with CD PROJEKT RED.
