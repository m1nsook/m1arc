## Try M1 Arc

Explore the **browser-only demonstration** of the planned 1.1.0 interface. Select a registered mod, change settings, switch themes, use Quick Search or inspect simulated diagnostic logs. The Feature Showcase includes tabs, master and group switches, cross-tab dependencies and example actions. The other examples use real mod manifest settings.

<M1Preview />

<Callout kind="info" title="Preview only">The demo does not connect to Cyberpunk, access installed mods or change game settings. Values and logs are simulated in the current page session.</Callout>

## Offline by design

No accounts, API keys or telemetry are required by the in-game framework. Community documentation; not affiliated with CD PROJEKT RED.
