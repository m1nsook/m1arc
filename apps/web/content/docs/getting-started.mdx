## Edit your first page

Open `content/docs/index.mdx` and change the title, description, and content. Reload the page to see the changes.

<Callout kind="info" title="One dependency">
  Every NextGuide component is shipped inside the single `nextguide` package. You do not need to install multiple UI libraries or copy component code.
</Callout>

## Add new pages

Use the CLI to create the content file and sidebar entries:

<CodeWindow language="bash" title="Add a guide" code="bunx nextguide page add guides/installation --title Installation" />

## Use MDX components

You can immediately write `<Callout />`, `<CodeWindow />`, `<Steps />`, `<FileTree />`, `<Tabs />` and the other exported NextGuide UI components in your MDX files. The starter has already registered them.
