M1 Arc is a native **RED4ext** plugin for **Cyberpunk 2077 2.50**.
Install RED4ext and REDscript before installing M1 Arc.

## Download and install

<Steps>
  <Step title="Download M1 Arc">Find an available version on [GitHub Releases](https://github.com/m1nsook/m1arc/releases) or [Nexus Mods](https://www.nexusmods.com/cyberpunk2077/mods/39311). Download its game-root ZIP and SHA-256 checksum.</Step>
  <Step title="Install the requirements">Install RED4ext and REDscript for your game version. Close Cyberpunk 2077 before copying files.</Step>
  <Step title="Extract into the game root">Extract the ZIP contents into the directory containing red4ext and r6. Do not create a separate package folder.</Step>
  <Step title="Launch and configure">Start Cyberpunk 2077. Capture your preferred menu shortcut, save it and reopen M1 Arc using that shortcut.</Step>
</Steps>

The ZIP installs `red4ext/plugins/m1arc/m1arc.dll`, its fonts and
language files, and `r6/scripts/m1arc/M1Arc.reds`. Regular releases do not
include the development-only UI Test fixture or gameplay mods.

Existing `red4ext/plugins/m1arc/settings.json` stores personal settings
and is not included in the release archive. Do not delete it while updating.

## Updating from 1.0.0 to 1.0.1

Install the complete new ZIP over the previous version with the game closed.
Keep your existing settings.json. On launch, choose and save your menu
shortcut again to complete the one-time migration. Your mod settings, profiles,
theme and language preferences are preserved. Open M1 Arc and acknowledge the
welcome message. Future updates can show their own welcome without requiring
another shortcut reset unless a migration needs it.

## Open the panel

The selected key opens and closes the panel. You can rebind it inside M1 Arc.
The panel includes light/dark themes, mod-specific controls and profile saving.
From 1.0.1, click the clipboard icon in the header to switch to [per-mod logs and diagnostics](/diagnostics).

## Install mods that support M1 Arc

The framework itself is not a gameplay mod. Mod authors provide their own
`mod.json` and `settings.json` under
`red4ext/plugins/m1arc/mods/<mod-id>/`, plus any ordinary REDscript under
`r6/scripts/`. See the [manifest guide](/mod-manifest).

For errors or compatibility issues, read [troubleshooting](/troubleshooting).
