## Markdown basics

Write headings, lists, tables, links and fenced code blocks as normal Markdown. The sidebar is generated from MDX files and optional `_meta.json` files.

## Content structure

Use `bunx nextguide page add guides/new-page --title "New page"` to create a new page without manually wiring navigation.
