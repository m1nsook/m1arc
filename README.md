# M1 Arc documentation

Built with NextGuide in Developer Mode.

```sh
bun install
bun run dev
```

Open http://localhost:3000/m1arc/. Run `bun run check` to validate the static export. Edit `content/docs/*.mdx` and `nextguide.config.json`.

NextGuide is installed from its published npm alpha channel. No private repository checkout is required. The development preview is not a released version of M1 Arc.
