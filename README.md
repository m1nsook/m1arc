# M1 Arc

Native in-game settings menu for Cyberpunk 2077 mods, built with RED4ext and Dear ImGui.

## Downloads

- [Nexus Mods](https://www.nexusmods.com/cyberpunk2077/mods/39311)
- [GitHub Releases](https://github.com/m1nsook/m1arc/releases)

## Requirements

- Cyberpunk 2077 2.50
- RED4ext
- REDscript

## Menu shortcut

On first launch, click **Capture**, press your preferred key (optionally with Ctrl and/or Shift), then click **Save**. Existing 1.0.0 bindings are preserved. If you accidentally choose a key or forget your shortcut, press **Ctrl + Shift + F11** in the focused game to reopen the shortcut setup. This combination is reserved for recovery.
